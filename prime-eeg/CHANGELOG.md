# Changelog

## 0.1.0 — curated frozen-detector release

- Extract active numerical functions/classes and constants into a standalone package; retain source and syntax provenance.
- Replace workstation paths with explicit dataset/cache/output arguments, package the frozen cohort split metadata and 21 fold rules, and make generated cache paths relative.
- Exclude unused experimental models, optional-dependency stubs, private working records, raw data, derived arrays and weights from the release tree. Nothing is deleted from the original project.
- Add safe new-output-only entry points, small reference ledgers, automated synthetic tests and CI configuration.
- Correct documentation-only descriptions of Fisher-z pair correlations, background alignment, event scoring and annotation-simulated confirmation. Numerical expressions and model parameters are unchanged.
- Carry forward the existing repeated-cluster macro confidence-interval reporting correction. No retuning, new primary predictions or claim of external validation.
- Leave neural inference and its historical candidate sweeps outside the detector package; document this reproduction limit explicitly.
- No software license added.
